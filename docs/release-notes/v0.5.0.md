# Aski v0.5.0

`v0.5.0` is a pre-1.0 additive roll-up of every change merged between `v0.4.0` and `v0.5.0`. Default
rendered output is unchanged — every new capability ships off by default and the snapshot baselines are
byte-identical to `v0.4.0`.

## Highlights

- **Full video + GIF pipeline.** Streaming MP4 → ASCII → MP4 loops, animated-GIF ingest and export with
  per-frame delays, and target-FPS resampling for both formats. `ASCIIGIFEncoder`/`ASCIIGIFDecoder` are
  now part of the library.
- **HDR/EDR emissive render path (opt-in SPI).** `@_spi(AskiResearch)` `renderExtendedRangeImage(...)`
  authors a gain-map Adaptive HDR HEIC from a linear-domain per-cell emission gain. The default render
  path is byte-identical.
- **Helmlab palette matching.** Two opt-in policies — `helmlabEuclidean` and `helmlabCompressed` — backed
  by a full Helmlab v21 MetricSpace port. The default remains `oklabEuclidean`.
- **Faithful aspect-ratio rendering.** New `preserveSourceAspect` renderer option reproduces the source
  aspect ratio; default off, snapshots unchanged. `AskiDemo` opts in via `--preserve-aspect`.
- **CLI tools unified on swift-argument-parser.** `--help` and `--version` (build SHA) work uniformly
  across every tool.

## Video

The C2 work completes the video story: streaming MP4 round-trip (ASTSK-3, including the encoder
deadlock fix), animated-GIF ingest + export (ASTSK-13), and target-FPS resampling for MP4 and GIF
(ASTSK-19). The `v0.5.0` tag adds source `preferredTransform` handling (ASTSK-12), but that tagged
implementation still vertically flips rotated/portrait clips. The complete orientation fix landed after
`v0.5.0` in ASTSK-38 and is tracked in [CHANGELOG.md](../../CHANGELOG.md) under v0.6.0.

## Color & shape

New surface is additive and off by default:

- Helmlab palette-matching policies (ASTSK-2) and the per-cell shape residual via `convertWithResidual`.
- Character-set `.bin` v2 raw ink-density (`rawDensityValues`, ASTSK-28) and `.bin` v3 shape-structure
  channels (ASTSK-35), both backward-compatible.
- Default-off research knobs: ink-fraction pre-compensation (ASTSK-29), `chromaShapeAssist` isoluminant
  rescue (ASTSK-30), `occupancyMatching` (ASTSK-7), and `shapeStructureAssist` (ASTSK-35).
  `shapeStructureAssist` ships as a **documented negative result** — its lab ρ lift does not transfer to
  production glyph picks — and is not recommended.

## Research

This cycle is research-heavy: NASA isoluminant corpus validation (ASTSK-37), λ dose-response ramps
(ASTSK-36), a regime-appropriate structure oracle re-settling the shape-residual verdict (ASTSK-31),
Color-Theory Phase 0 composited-cell oracle, CAM16/HCT and Color.js gamut reference cross-checks, and
research data/results-store conventions (ASTSK-11). New `swift run` harnesses: `AskiMotionLab`,
`AskiVideoLab`, `AskiAccessLab`, `AskiDecolorLab`, and `AskiHDRLab`.

## Migration

No source change is required. All new color/shape capabilities are opt-in knobs or research SPI that are
off by default, and default rendered output is unchanged. The only rename is the internal tool-support
target (`AskiDemoSupport` → `AskiToolSupport`, ASTSK-24), which does not affect the `Aski` library API.
