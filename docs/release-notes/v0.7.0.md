# Aski v0.7.0

**Pictures, reconsidered as type. Now with a public front door.**

`v0.7.0` is the first release on this repository's public history. The history begins at a single
root commit that holds the code and the published research; development before it happened in a
private repository. The `v0.6.0` tag and earlier tags do not exist here. Issue, pull-request and
commit references in the changelog and under `docs/` from before this release point to that
private history.

## Highlights

- **A clearer way in.** The [README](../../README.md) now starts with a bundled-image demo and
  Swift integration. A dedicated [command-line guide](../../Sources/Aski/Aski.docc/CommandLine.md),
  [contributor guide](../../CONTRIBUTING.md), refreshed DocC onboarding, and expanded `llms.txt`
  separate everyday use, development, and research. Current defaults, platform requirements,
  plain-text/color behavior, and experimental boundaries are explicit.
- **Unified `aski lab` command tree (ASKI-48).** `aski lab {color,motion,video,accessibility,decolor,hdr,preset}`
  replaces the separate lab executables, with Bash, Zsh and Fish completions for the full tree. The
  historical `Aski*Lab` products remain as thin shims with identical help, usage and exit codes.
- **Masks and photo dissolve in the CLI (ASKI-43, ASKI-44).** `aski render --mask` accepts raster
  masks with transparent, solid-color or original-photo fallbacks, sizing modes, hard edges and
  inversion. The new `MaskOptions.groundColor` places a color behind active glyphs and tiles.
- **Exact target-width PNGs (ASKI-63).** `ASCIIGrid.renderImage(font:backgroundColor:targetPixelWidth:preserveSourceAspect:)`
  and `aski render --width` render to an exact pixel width, supersampled 4x and averaged down in
  linear light. PNG size no longer depends on `--font-size`.
- **Bottom and right edges are sampled again (ASKI-65).** Converters used to skip the last
  `height % rows` rows and `width % columns` columns of the source, up to 10% of the image height,
  and the result looked stretched downward. The full image is now sampled; every rendered-grid
  golden was re-recorded with no tolerance loosened.
- **Transparent PNG backgrounds.** `aski render --background clear` (or `transparent`) produces an alpha-zero
  ground for `--render-png`. The opaque-black default is unchanged.

## Breaking changes

- **`ASCIIAlgorithm.edgeMap` is removed (ASKI-16).** It picked the wrong stroke orientation in 9 of
  20 test cases even after two fixes. Use `.logPolar` (the default) or `.dotMatrix`. Removing
  `edgeMap` did not change those algorithms; the separate sampling fix above can change output.
- **`RenderingOptions` has five public controls instead of twelve (ASKI-68).** Occupancy matching,
  shape-structure assist, steerable-shape assist, ink pre-compensation and chroma-shape assist were
  default-off experiments that failed or stayed inconclusive; they are gone from the public API.
- **Custom character sets are snapshotted (ASKI-71).** `ASCIIConverter` copies a character set's
  glyph arrays when it is initialized or when `characterSet` is assigned. A reference-type set that
  mutates its arrays in place must be assigned again before the next conversion.
- **`swift-argument-parser` minimum 1.8.0 (ASKI-47).** The requirement is now `from: "1.8.0"`.

## Migration

After the tag is published, consumers moving from private-history pins can adopt the public
repository with an exact version:

```swift
.package(url: "https://github.com/BigCactusLabs/Aski.git", exact: "0.7.0"),
```

Before publication, use a source checkout or a local package dependency. Aski is pre-1.0;
exact pins make upgrades deliberate rather than promising source or output stability.

Code using `.edgeMap` or removed `RenderingOptions` controls needs the changes above. Custom
character-set owners should review snapshot semantics. For earlier API changes and before/after
examples, see [Migration Notes](../../Sources/Aski/Aski.docc/Migrating-to-A1.md).

## For contributors

- Render goldens and `default.metallib` are recorded on macOS 27 / Xcode 27 (ASKI-77); the render
  snapshot suites fail on macOS 26. Glyph selection output is unchanged by that baseline refresh.
- `just doctor` and `just release-preflight` no longer require a specific Xcode; the Swift minimum
  comes from `swift-tools-version`.
- The [contributor guide](../../CONTRIBUTING.md) distinguishes library deployment minimums from
  snapshot requirements and explains the local gates. This repository has no hosted CI workflow.
