# Aski v0.6.0

> **Private-history document.** These notes were written for the `v0.6.0` release of the earlier
> repository and are kept as a record. The `v0.6.0` tag and earlier tags do not exist in this
> repository, whose history begins at `v0.7.0`; statements below about where the published history
> begins, and the advice to repoint to `v0.6.0`, describe that earlier repository. Pin to `v0.7.0`
> or later instead — see the [v0.7.0 release notes](v0.7.0.md).

`v0.6.0` is the first public release of Aski, under the Apache-2.0 license. The code is identical to
the final private-repo state; the change from `v0.5.0` is the accumulated post-`v0.5.0` work listed
below, plus the license and the published history starting fresh at this tag.

## Highlights

- **Canonical Vesper render preset (ASTSK-47).** New public `VesperPreset` — `VesperPreset.canonical`
  is the built-in frozen duotone share look (blocks charset, 76 columns, bone `#E8E2D2` sRGB figure on
  oxblood `#5E1B18` Display P3 ground, `.wide` + aspect-faithful render, bundled Courier Prime), with
  `render(_:)` as its single entry point. Purely additive; existing API output is byte-identical.
- **Video quality and cosmetic levers (ASTSK-39, ASTSK-44).** `AskiVideoLab` exposes the per-frame
  quality knobs, a time-modulated `--pattern` overlay, and opt-in `--bloom`/`--scanlines`/`--vignette`.
  All default to off, so prior output is byte-identical.
- **Parallel per-cell conversion walk (ASTSK-51).** The per-cell grid loop walks rows in parallel behind
  a grid-size gate across all four conversion entry points. Output is byte-identical to the previous
  serial walk; default single-still converts run ~18–40% faster at and above the threshold.
- **Bounded video export pipeline (ASTSK-52).** `convertVideo` overlaps decode + conversion of the next
  frame with render + encode of the current one through a one-frame prefetch, with a structurally
  bounded resident peak.
- **Portrait-aspect blank-render fix (found during ASTSK-47).** Portrait inputs no longer collapse to
  one-pixel-wide cells and render blank under `.logPolar`; square and landscape output is
  byte-identical.
