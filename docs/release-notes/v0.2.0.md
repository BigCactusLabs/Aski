# Aski v0.2.0

First tagged release after `v0.1.0`. Bundles every change merged to `main` between the two tags, plus the close-out surface debt (root `DESIGN.md` and `llms.txt`, `CHANGELOG.md`, the consolidated v0.1.0 → v0.2.0 migration section, and the tag-triggered Release-assets workflow).

## Highlights

- **A1 — Character-mode expansion.** New `ASCIIAlgorithm` cases (`.logPolar`, `.edgeMap`, `.dotMatrix`), seven new built-in character sets, Courier Prime factory, a Braille rasterizer, edge-map + dot-matrix kernels, the `RenderingOptions` API. This is a source-breaking expansion against v0.1.0.
- **Tile-grid output, effects, masks, animation.** Subsystems A2, B (Phase 1 and Phase 2), D, and C1 all shipped in this window. See `CHANGELOG.md` § 0.2.0 § Added for the PR-by-PR breakdown.
- **Color Pipeline v2 Phase 1.** New `PaletteContent` + `PaletteColor(_:colorSpace:)` API with sRGB / Display P3 declared components. Removes `colorsOKLAB` from custom palette sources.
- **`AskiColorLab` research harness.** Five lab commands for color-pipeline ablation studies; not part of the public Aski library but ships in the same package via the `Tools/` target.
- **OKLab conversion uses `cbrt`.** Cleaner numerics, identical round-trip tolerance, drift gates installed.
- **DocC Markdown export.** This release is the first to attach a `Aski-markdown-manifest.json` and `aski-docc-markdown.tar.gz` as Release assets — see § Assets below.

## Migration

If you are upgrading from `v0.1.0`, read [`Sources/Aski/Aski.docc/Migrating-to-A1.md`](../../Sources/Aski/Aski.docc/Migrating-to-A1.md), specifically the *Migrating from v0.1.0 → v0.2.0* section. The cumulative removals are `ASCIIConverter.widthRatio` (use `ASCIITileShape`) and the `colorsOKLAB` palette property (use `PaletteContent` + `PaletteColor`).

## What's NOT in v0.2.0

Five promotions from earlier close-out spec drafts defer to `v0.3.0` or later: `PaletteMatchingPolicy.oklabHyAB`, `PaletteMatchingPolicy.helmlabMetric`, `RenderColorSpacePolicy.extendedLinear`, the linear-light sampling default flip, and the Ray Trace gamut policy default.

## Assets

- `Aski-markdown-manifest.json` — DocC Markdown manifest indexing all public API symbols with anchors and cross-references. The `llms.txt` `/releases/latest/download/` URL pattern resolves to this asset on each tagged release.
- `aski-docc-markdown.tar.gz` — Tarball of per-symbol Markdown sidecars. Useful for agent tooling that wants offline DocC content.
