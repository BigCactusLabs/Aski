# Aski v0.3.1

Correctness release after `v0.3.0`. The default per-cell color sampler now averages in linear light, and release documentation corrects the Helmlab promotion framing.

## Highlights

- **Linear-light sampling is now the default.** `ASCIIConverter.colorSampling` defaults to `.linearLightAverage` instead of `.encodedAverageLegacy`, matching the physically-correct sampling policy already available as an opt-in.
- **Legacy output remains available.** Callers that need `v0.3.0`-style encoded averaging can pass `colorSampling: .encodedAverageLegacy` explicitly.
- **Snapshot baselines were regenerated only where bytes changed.** The observed scope was four image snapshots: one mixed-charset render, two circle-mask fallbacks, and one soft-edge mask fixture.
- **Helmlab promotion paused.** The docs now state that Helmlab is a separate color space with its own MetricSpace pipeline, not a one-line metric on OKLab inputs. A fresh spec is required before any Helmlab implementation.

## Migration

If exact `v0.3.0` rendered colors matter, construct the converter with `colorSampling: .encodedAverageLegacy`. Otherwise, no source change is required.

```swift
let converter = ASCIIConverter(
    characterSet: .standard,
    palette: .fullColor,
    colorSampling: .encodedAverageLegacy
)
```

## What's NOT in v0.3.1

- Ray Trace gamut mapping is not the production default.
- `PaletteMatchingPolicy.helmlabMetric` is not implemented.
